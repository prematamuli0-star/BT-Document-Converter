# BT Document Converter — Phase 2 Offline PDF Foundation

This is a Kotlin/Jetpack Compose Android Studio project.

Included:
- Blue/white Material 3 starter UI
- Android Storage Access Framework document selection
- Offline Image-to-PDF and Text-to-PDF using Android PdfDocument
- PDF merge, single-page extraction and rotation using PDFBox-Android
- Android 7.0+ minimum SDK (API 24)

Build with Android Studio and JDK 17. This source is not yet a signed APK/AAB.
PDFBox operations need device testing with large, encrypted, malformed and
real-world PDFs before production release.

Not included yet: Office/PDF bidirectional conversion, OCR integration, online
hybrid server, paid fallback, AdMob/UMP, privacy policy and Play Store release QA.
